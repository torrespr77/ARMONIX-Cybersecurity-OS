# Skill: E-commerce Dropshipping

## Descripción
Gestión automatizada de tiendas e-commerce con modelo dropshipping. Cubre importación de productos, gestión de inventario, procesamiento de pedidos, integración con proveedores y optimización de la tienda.

## Plataformas soportadas
- **Shopify** (recomendado, con Shopify AI Toolkit disponible)
- **WooCommerce** (WordPress)
- **Tiendanube** (popular en Latinoamérica)
- **Mercado Libre** (marketplace)

## Proveedores de dropshipping
- **AliExpress** (el más popular, envío mundial)
- **CJ Dropshipping** (almacenes en EUA y China)
- **Zendrop** (envío rápido desde EUA)
- **Spocket** (proveedores de EUA y Europa)
- **Printful / Printify** (print-on-demand)
- **Proveedores locales de México** (para envío más rápido)

## Procesos a automatizar

### 1. Importación de productos
```
Proveedor → Extracción de datos (API/scraping) → Normalización → Publicación en tienda
```

### 2. Actualización de inventario
```
Proveedor → Verificar stock → Actualizar cantidades en tienda → Ocultar agotados
```

### 3. Actualización de precios
```
Proveedor → Verificar precio → Aplicar margen → Actualizar precio de venta
```

### 4. Procesamiento de pedidos
```
Pedido en tienda → Notificación al proveedor → Confirmación de envío → Tracking → Cliente notificado
```

### 5. Atención al cliente
```
Consulta → Chatbot/FAQ → Estado de pedido → Devoluciones → Reseñas
```

### 6. Marketing automatizado
```
Redes sociales → Publicaciones automáticas → Email marketing → Retargeting
```

## Herramientas de automatización
- **Shopify AI Toolkit** (skills oficiales para gestión de tienda)
- **n8n** (flujos de trabajo automatizados)
- **Make.com** (integraciones visuales)
- **Zapier** (conexiones sencillas)
- **DSers / Oberlo** (integración AliExpress-Shopify)
- **AutoDS** (gestión completa de dropshipping)

## Preguntas clave para personalizar (consultar al cliente)
1. ¿Qué tipo de productos vendería?
2. ¿Ya tiene nombre para la tienda?
3. ¿En qué plataforma está la tienda? (Shopify, WooCommerce, etc.)
4. ¿Qué proveedores de dropshipping usaría?
5. ¿Qué procesos quiere automatizar?
6. ¿Usaría n8n, Make.com, o ambos?
7. ¿Necesita integración con marketplaces? (Amazon, Mercado Libre)
8. ¿Tiene experiencia previa con dropshipping?
9. ¿Cuál es su presupuesto mensual para herramientas?
10. ¿Vendería solo en México o también a otros países?

## Notas técnicas
- Para Shopify: usar los skills del Shopify-AI-Toolkit (shopify-admin, shopify-customer, shopify-storefront-graphql)
- Para n8n: referirse a los skills oficiales de n8n-io/skills
- Cumplimiento fiscal: considerar facturación electrónica (CFDI) si vende en México
- Tiempos de envío: informar al cliente tiempos reales desde China (15-30 días) vs proveedores locales (3-7 días)
- Margen de ganancia: típicamente 20-40% sobre precio de proveedor
